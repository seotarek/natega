# منظومة استعلام نتائج الطلاب - Natega System 🎓

نظام عالي الأداء لاستعلام وبحث نتائج الطلاب، مصمم بالكامل للتعامل مع قواعد البيانات الضخمة (تستوعب أكثر من **919,000 طالب وطالبة**) باستجابة فائقة في أقل من 5 مللي ثانية (ms).

![Natega UI](public/index.html)

## 🌟 المميزات والخصائص

- **محرك بحث فوري وسريع:** دعم كامل للبحث برقم الجلوس أو اسم الطالب (معالجة الحروف العربية والهمزات والتشكيل تلقائياً).
- **لوحة مؤشرات إحصائية (KPI Dashboard):** عرض إجمالي المقيدين، نسبة النجاح العامة، ومتوسط الدرجات، وطلاب الدور الثاني.
- **تصفية متقدمة:** فلترة النتائج حسب حالة الطالب (ناجح دور أول - دور ثان - راسب - غياب كلي).
- **تصميم عصري متجاوب (RTL):** يدعم الوضع الليلي (Dark Mode) والوضع الفاتح (Light Mode) مع واجهة Glassmorphism جذابة.
- **طباعة بطاقة الطالب:** معاينة وطباعة بطاقة نتيجة الطالب (Result Card) بضغطة زر.
- **تصدير البيانات:** تصدير النتائج المفلترة مباشرة إلى ملف CSV بترميز UTF-8 المتوافق مع برنامج Excel.

---

## 🛠️ التكنولوجيا المستخدمة

- **الخلفية (Backend):** Node.js / Express.js
- **قاعدة البيانات (Database):** SQLite3 مع فهرسة كاملة ومحرك البحث النصي FTS5 (Better-SQLite3)
- **الواجهة الأمامية (Frontend):** HTML5, Pure CSS3, JavaScript (ES6+ Vanilla), FontAwesome Icons

## 🚀 كيفية التشغيل والتركيب

### 1. استنسخ المستودع (Clone repository):
```bash
git clone https://github.com/seotarek/natega.git
cd natega
```

### 2. تثبيت الحزم والمكتبات:
```bash
npm install
```

### 3. تشغيل الخادم المحلي:
```bash
node server.js
```
افتح المتصفح على العنوان: `http://localhost:3000`
